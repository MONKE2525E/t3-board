Open a thread

Hold Super and press a lit key. Super+F1 to F12 and Super+Delete open that agent in T3 Code.

Super+`, the key below Esc, opens the Esc agent. Super+Esc opens the system menu. Dark keys, simulation keys and unsent drafts do nothing.

How it connects

The installed desktop integration reports drafts after T3 Code is reopened through its normal launcher. For a browser-based T3 session, copy the bridge and run it once in the developer console. It sends only a thread ID and drafting events.
